# Sky-Mark Chrome拡張機能 インストール・使い方マニュアル

スカイマークの搭乗履歴を自動で取得し、確定申告用のデータとして表示・ダウンロードできるChrome拡張機能です。

---

## 全体の流れ

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│  ① ZIPをダウンロード                                │
│       ↓                                             │
│  ② ZIPを展開（解凍）                                │
│       ↓                                             │
│  ③ Chromeに拡張機能を読み込む                       │
│       ↓                                             │
│  ④ スカイマークにログイン                           │
│       ↓                                             │
│  ⑤ 拡張機能の設定ページで「Extract」ボタンを押す    │
│       ↓                                             │
│  ⑥ 搭乗履歴が表示される → CSV/JSONダウンロード     │
│                                                     │
└─────────────────────────────────────────────────────┘
```

---

## ① ZIPファイルをダウンロードする

1. 以下のリンクをクリックして、リリースページを開きます

   **https://github.com/RyosukeMondo/sky-mark/releases**

2. 最新のリリース（例: `v1.0.0`）の下にある **Assets** という見出しを探します

   ```
   Assets                          ← ここを探す
   ─────────────────────────────
   📦 skymark-extension-v1.0.0.zip   ← これをクリック
   ```

3. **`skymark-extension-v1.0.0.zip`** をクリックしてダウンロードします

4. ダウンロードが完了すると、画面の左下（または右上）に表示されます

   ```
   ┌──────────────────────────────┐
   │ 📦 skymark-extension-v1.0.0 │
   │    .zip                      │
   │    ダウンロード完了           │
   └──────────────────────────────┘
   ```

---

## ② ZIPファイルを展開（解凍）する

### Windowsの場合

1. ダウンロードフォルダを開きます
   - キーボードの `Windowsキー + E` を同時に押す → 「ダウンロード」をクリック

2. `skymark-extension-v1.0.0.zip` を見つけます

3. ファイルを **右クリック** → **「すべて展開」** をクリック

   ```
   ┌─────────────────────────┐
   │  右クリックメニュー      │
   ├─────────────────────────┤
   │  開く                    │
   │  すべて展開...      ← これ│
   │  切り取り                │
   │  コピー                  │
   └─────────────────────────┘
   ```

4. 展開先はそのまま（変更不要）で **「展開」** ボタンをクリック

5. 展開されたフォルダの中に **`extensions`** フォルダがあります

   ```
   📁 ダウンロード
    └── 📁 skymark-extension-v1.0.0
         └── 📁 extensions        ← このフォルダを使います
              ├── 📄 manifest.json
              ├── 📄 background.js
              ├── 📄 content.js
              ├── 📄 options.html
              ├── 📄 options.js
              ├── 📄 options.css
              └── 📁 icons
   ```

### Macの場合

1. ダウンロードフォルダで `skymark-extension-v1.0.0.zip` を **ダブルクリック**
2. 自動で展開され、同じ場所に `skymark-extension-v1.0.0` フォルダができます
3. その中の **`extensions`** フォルダを使います

---

## ③ `extensions` フォルダのパス（場所）をコピーする

次のステップでChromeに場所を教える必要があるため、フォルダの場所をコピーしておきます。

### Windowsの場合

1. `extensions` フォルダを開きます（ダブルクリック）

2. 画面上部のアドレスバー（フォルダの場所が表示されている部分）をクリック

   ```
   ┌─────────────────────────────────────────────────────┐
   │ ← → ↑ │ 📁 > ダウンロード > skymark-ext... > extensions │
   └─────────────────────────────────────────────────────┘
                ↑ この部分をクリックすると文字が青く選択される
   ```

3. 文字が青く選択されたら `Ctrl + C` でコピー

   コピーされる内容の例：
   ```
   C:\Users\あなたの名前\Downloads\skymark-extension-v1.0.0\extensions
   ```

### Macの場合

1. `extensions` フォルダを **右クリック**
2. **`Option`キーを押しながら** メニューを見ると「"extensions"のパス名をコピー」が表示される
3. それをクリック

---

## ④ Chromeに拡張機能を読み込む

### 4-1. 拡張機能の管理ページを開く

1. Chromeを開きます

2. アドレスバー（URLを入力する場所）に以下を入力して `Enter` を押します

   ```
   chrome://extensions
   ```

   ```
   ┌─────────────────────────────────────────────┐
   │ 🔒 chrome://extensions          ← ここに入力 │
   └─────────────────────────────────────────────┘
   ```

### 4-2. デベロッパーモードをオンにする

1. 画面の **右上** に「デベロッパー モード」というスイッチがあります

2. スイッチをクリックして **オン（青色）** にします

   ```
   変更前:                    変更後:
   ┌──────────────────┐      ┌──────────────────┐
   │ デベロッパー モード │      │ デベロッパー モード │
   │     ○──┐  OFF    │      │     ┌──●  ON     │
   └──────────────────┘      └──────────────────┘
   ```

3. オンにすると、画面上部に3つのボタンが表示されます

   ```
   ┌────────────────┐  ┌────────────────┐  ┌──────────────┐
   │ パッケージ化    │  │ 展開して読み込み │  │ 更新          │
   │ されていない...  │  │                │  │              │
   └────────────────┘  └────────────────┘  └──────────────┘
                              ↑
                         これを押します
   ```

### 4-3. フォルダを選択して読み込む

1. **「展開して読み込み」** ボタンをクリック

2. フォルダ選択ダイアログが開きます

3. ②でコピーしたパスを使って `extensions` フォルダを選択します

   **方法A:** アドレスバーに直接パスを貼り付け（`Ctrl + V`）て `Enter`

   **方法B:** フォルダを手動でたどる
   ```
   📁 PC
    └── 📁 ダウンロード
         └── 📁 skymark-extension-v1.0.0
              └── 📁 extensions   ← これを選択
   ```

4. **「フォルダーの選択」** ボタンをクリック

5. 読み込みが成功すると、拡張機能の一覧に表示されます

   ```
   ┌──────────────────────────────────────────┐
   │ 🧩 Sky-Mark Flight History               │
   │    Skymark Airlines flight history...     │
   │    ID: abcdef1234567890                   │
   │                                           │
   │    ☑ 有効   [詳細]   [削除]              │
   └──────────────────────────────────────────┘
   ```

## ⑤ 拡張機能をピン留めして、設定ページを開く

### 5-1. ツールバーにピン留めする

1. Chrome画面の **右上** にある パズルピースのアイコン 🧩 をクリック

   ```
   Chromeの右上:
   ┌──────────────────────────────┐
   │            🧩  👤  ⋮        │
   │            ↑                 │
   │       このアイコン            │
   └──────────────────────────────┘
   ```

2. 拡張機能の一覧が表示されます

3. **「Sky-Mark Flight History」** の右にある **ピンのアイコン 📌** をクリック

   ```
   ┌──────────────────────────────────┐
   │ 拡張機能                          │
   ├──────────────────────────────────┤
   │ 🧩 Sky-Mark Flight History  📌  │  ← ピンをクリック
   │ 🧩 その他の拡張機能...      📌  │
   └──────────────────────────────────┘
   ```

4. ツールバーにアイコンが常時表示されるようになります

### 5-2. 設定ページ（オプション）を開く

1. ツールバーの **Sky-Mark アイコンを右クリック**

2. メニューから **「オプション」** をクリック

   ```
   ┌──────────────────┐
   │  右クリックメニュー│
   ├──────────────────┤
   │  オプション    ← これ│
   │  サイトデータ... │
   │  拡張機能を管理  │
   │  Chromeから削除  │
   └──────────────────┘
   ```

3. 新しいタブで設定ページが開きます（このページは **開いたまま** にしてください）

## ⑥ スカイマークにログインする

1. **新しいタブ** を開きます（`Ctrl + T` または `Command + T`）

2. 以下のURLにアクセスします

   ```
   https://www.skymark.co.jp/ja/mypage/
   ```

3. メールアドレスとパスワードを入力してログインします

4. **マイページが表示された状態** にしてください

   ```
   ┌──────────────────────────────────────────┐
   │ 🔒 www.skymark.co.jp/ja/mypage/          │
   ├──────────────────────────────────────────┤
   │                                           │
   │   マイページ                               │
   │                                           │
   │   予約便一覧                               │
   │   搭乗実績                                 │
   │   ...                                     │
   │                                           │
   └──────────────────────────────────────────┘
   ```

> **重要:** マイページのタブは **閉じないで** ください。
> 拡張機能がこのページからログイン情報を読み取ります。

## ⑦ 搭乗履歴を取得する

いま開いているタブが2つある状態です：

```
┌──────────────┐  ┌──────────────────────────┐
│ Sky-Mark      │  │ マイページ - スカイマーク   │
│ オプション     │  │                           │
└──────────────┘  └──────────────────────────┘
  ↑ 設定ページ       ↑ スカイマークのマイページ
```

### 7-1. 設定ページに戻る

1. **Sky-Mark のオプションページ** のタブをクリックして戻ります

### 7-2. 年度を選択する

1. ページ上部の **年度選択** ドロップダウンで取得したい年を選びます

   ```
   ┌────────────────────────────────────────────┐
   │  年度: [2025年 ▼]   [Extract]  CSV  JSON  │
   └────────────────────────────────────────────┘
             ↑                ↑
        年を選ぶ          次にこれを押す
   ```

### 7-3. 「Extract」ボタンを押す

1. **「Extract」** ボタンをクリック

2. 進行状況が表示されます

   ```
   Refreshing authentication token...
   ████████░░░░░░░░░░░░  10%

   Fetching reservation 3/25: SBMZRM
   ██████████████░░░░░░  55%

   Complete: 25 reservations
   ████████████████████  100%
   ```

3. 完了すると搭乗履歴の表が表示されます

> **取得には数十秒かかります。** 予約件数 x 1秒 程度お待ちください。
> 途中でページを閉じないでください。

## ⑧ データを確認・ダウンロードする

取得完了後、3つの表が表示されます：

### 搭乗便一覧

便ごとの詳細（日付、便名、区間、運賃、座席、PNRなど）

### 月別集計

月ごとのフライト数と合計金額

### 費用種別集計

運賃・手荷物料金・座席指定料金などの内訳

### ダウンロード

```
┌──────────────────────────────────────────────┐
│  年度: [2025年 ▼]  [Extract]  [CSV]  [JSON] │
│                                     ↑     ↑  │
│                              Excelで   生の  │
│                              開ける    データ │
└──────────────────────────────────────────────┘
```

- **CSV** ボタン: Excel等で開けるファイル（`.csv`）をダウンロード
  - 確定申告の添付資料や、経理への提出に便利です
- **JSON** ボタン: プログラム用のデータファイル（`.json`）をダウンロード

## よくあるトラブルと対処法

### 「No Skymark mypage tab found」と表示される

→ スカイマークのマイページが開かれていません。
別のタブで `https://www.skymark.co.jp/ja/mypage/` を開いてログインしてください。

### 「No Cognito refresh token found」と表示される

→ ログインの有効期限が切れています。
スカイマークのマイページを開き直し、再度ログインしてください。

### 「Cannot reach content script」と表示される

→ 拡張機能の読み込み後にスカイマークのページを開いた場合、拡張機能がまだ反映されていません。
スカイマークのマイページのタブで **`F5`キー** を押してページを再読み込みしてください。

### 搭乗便一覧に何も表示されない

→ 選択した年度にフライトがない可能性があります。年度を変更して再度Extractしてください。

## 拡張機能のアップデート方法

新しいバージョンがリリースされたら：

1. リリースページから新しいZIPをダウンロード
2. 展開して、既存の `extensions` フォルダを上書き
3. `chrome://extensions` を開き、Sky-Mark の **「更新」** ボタン（または`Ctrl+R`）をクリック

---

## アンインストール方法

1. `chrome://extensions` を開く
2. 「Sky-Mark Flight History」の **「削除」** をクリック
3. ダウンロードした `skymark-extension-v1.0.0` フォルダを削除
